# Projeto Include

## Sobre o projeto
O Projeto Include é um MVP de uma aplicação web responsiva voltada à organização de atividades educacionais.

## Objetivo
Facilitar o gerenciamento de alunos, turmas e registros de frequência em organizações educacionais.

## Funcionalidades previstas
- Cadastro de alunos.
- Cadastro e gerenciamento de turmas.
- Registro de frequência.
- Consulta ao histórico de frequência.

## Tecnologias previstas
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- PostgreSQL

## Arquitetura
Arquitetura monolítica em camadas, utilizando o padrão MVC (Model-View-Controller).
